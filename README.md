# 🏔️ Mountain Scenario Animation

An interactive **Computer Graphics project** developed using **OpenGL and GLUT**. The project presents an animated mountain environment with interactive keyboard and mouse controls.

The application demonstrates fundamental computer graphics concepts such as 2D rendering, geometric transformations, animation, user interaction, and real-time scene updates.

## 🎥 Project Overview

This project creates a visually interactive mountain scenario containing different environmental elements and animations. Users can interact with the scene using keyboard and mouse controls.

The main objective of this project is to demonstrate the practical implementation of OpenGL graphics programming concepts in an interactive animated environment.

## ✨ Features

* 🏔️ Interactive mountain scenery
* 🌄 Animated environmental elements
* 🎬 Real-time animation
* ⌨️ Keyboard interaction
* 🖱️ Mouse interaction
* 🔄 Object movement and transformation
* 🎨 OpenGL-based graphical rendering
* ⚡ Real-time scene updates using GLUT

## ⚙️ How to Run

### Requirements

Make sure the following are installed:

* C++ Compiler
* OpenGL
* GLUT or FreeGLUT

### Compile and Run

For systems using `g++` and FreeGLUT:

```bash
g++ src/main.cpp -o MountainScenario -lGL -lGLU -lglut
./MountainScenario
```

For Windows, configure OpenGL and GLUT libraries in your preferred IDE, such as:

* Code::Blocks
* Visual Studio
* Dev-C++
* CLion

Then build and run the project.
